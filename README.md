# Script2Scribe 📝

> Python tool that converts typed assignments into realistic handwritten pages.

Built this in my 2nd year to solve the real problem every MSBTE student faces - writing 100+ pages manually every semester.

### ✨ Features
- Converts typed text to handwritten style
- A4 pages with ruled lines
- Fast & customizable fonts
- Built with Python + Pillow

### 🛠️ Tech Stack
Python, Pillow (PIL)
